Скачать папку с Яндекс Диска целиком

Ссылка одна, файлов много. Сервис сам обойдёт вложенные папки, сохранит структуру и будет качать файлы по одному — те, что не получились, попадут в журнал.

Ссылка и место сохранения

Ссылку берут из кнопки «Поделиться» на Диске. Папка должна быть открыта по ссылке — закрытую сервис не увидит.

Куда сохранять

Выбор папки — Chrome и Edge. В других браузерах останутся «Загрузки».

    Отчёт о загрузке

    —

      Как это работает

      1. 1
        Ссылка. Вставьте адрес публичной папки и нажмите «Проверить папку».
      2. 2
        Папка. Выберите, куда сохранять: структура вложенных папок останется прежней.
      3. 3
        Файлы. «Скачать всё» — сервис идёт по файлам, показывает прогресс и складывает неудачи в журнал.

      Что важно знать

      • Работают только публичные ссылки. Закрытую папку сервис не откроет.
      • Яндекс может отказать отдельным файлам — это нормально, повторите их из журнала.
      • Вкладку можно свернуть, но не закрывать. Если закрыть или обновить страницу — вернитесь: сервис предложит продолжить с того же места, недокачанные файлы не останутся битыми.
      • 20 потоков быстрее, но Яндекс чаще отвечает «слишком часто». Начинайте с 5.

      Браузер

      Выбор папки и потоковая запись — Chrome и Edge 120+. Safari и Firefox скачивают в «Загрузки» без сохранения структуры.

      Внутренний инструмент для работы с материалами партнёров. Публичный API Яндекс Диска, без установки.
