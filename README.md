# Файлы с Диска · Этажи

Аналог сервиса «Диск по файлам» для «Этажей»: одна публичная ссылка на Яндекс Диск — и вся папка
скачивается по файлам, с вложенной структурой, прогрессом и журналом ошибок.

Работает как обычная страница в Chrome и Edge: ставить ничего не нужно, файлы пишутся прямо в
выбранную папку через File System Access API — без «Загрузок» и без диалога «разрешить несколько загрузок».

## Как запустить

**Сайт (для всех):** https://kurganecc-dev.github.io/etagi-disk/ — ничего ставить не нужно, работает в Chrome и Edge.

**Вариант 1 — один файл (для отправки партнёру).** Откройте `etagi-disk.html` двойным щелчком в Chrome.
Всё внутри: шрифты, логотипы, логика. Интернет нужен только для обращения к Яндексу.

**Вариант 2 — из папки (для правок и хостинга).** `start.command` (двойной щелчок) поднимает локальный
сервер и открывает страницу. Или вручную:

```bash
cd etagi-disk && python3 -m http.server 8777
open http://127.0.0.1:8777/index.html
```

`index.html` использует ES-модули, поэтому с `file://` он не откроется — нужен сервер или сборка.

После правок: `npm run build` пересобирает `etagi-disk.html`.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | страница сервиса (версия для сервера) |
| `etagi-disk.html` | та же страница одним файлом, без сервера |
| `css/app.css`, `js/app.js` | оформление по бренду и интерфейс |
| `js/engine.js` | движок: ссылка, обход папок, загрузка, ошибки, журнал. Без зависимостей |
| `assets/` | логотипы «Этажей», Circe в woff2 (кириллица + латиница) |
| `build.mjs` | сборка одного файла |
| `tests/engine.test.mjs` | проверки на реальной публичной папке «1_Логотипы» |

## Что умеет

- Ссылки `disk.yandex.ru/d/…`, `disk.yandex.com/d/…`, `yadi.sk/d/…`, ссылки с путём внутри папки и `/i/…` для одного файла.
- Обход вложенных папок с пагинацией, повтор на `429/5xx`, ограничение частоты запросов.
- Куда сохранять: папка на компьютере (структура сохраняется) или «Загрузки» (путь в имени через ` · `).
- 1 / 5 / 10 / 20 одновременных загрузок, прогресс по байтам, пауза, остановка без автоперезапуска.
- Зависшее соединение ловится по 20 секундам тишины и повторяется — файл не висит вечно.
- **Атомарная запись.** Файл пишется во временный `*.etagi-part` и переименовывается только после
  успешного завершения: недокачки не остаются под рабочими именами, `exists()` сверяет размер с Диском.
- **Продолжение после перезагрузки.** Задача и `FileSystemDirectoryHandle` хранятся в IndexedDB.
  После перезагрузки сверху появляется баннер «Продолжить»; Chrome один раз спросит доступ к папке.
- **Отчёт после каждой загрузки**: сводка и список неудачных файлов на странице, кнопки JSON/TXT,
  а в выбранную папку автоматически кладутся `_Отчёт.txt` и `_Отчёт.json`.
- Журнал ошибок с кодом и причиной, повтор ошибок и повтор из сохранённого журнала.
- Пропуск уже скачанного: размер в выбранной папке + история прошлых запусков (localStorage).

## Ограничения

- Только публичные ссылки: закрытую папку Яндекс не отдаёт без авторизации.
- Структуру сохраняет только выбор папки; в «Загрузки» файлы ложатся плоско.
- Загрузка идёт в странице: вкладку можно свернуть, но не закрывать. Закрыли/обновили — при следующем
  открытии сервис предложит продолжить с того же места (файлы сверяются по размеру, битые не считаются готовыми).
- Скорость упирается в `downloader.disk.yandex.ru`; на медленном канале большая папка идёт долго.

## Проверки

```bash
npm test           # 12 небольших файлов: обход, скачивание, сверка MD5, журнал
FULL=1 npm test    # вся папка «1_Логотипы» (39 файлов, 11,8 МБ)
```

Тест ходит в публичный API Яндекса. Он же проверяет разбор ссылок, отказ на некорректных ссылках
и повтор из журнала.

## Если понадобится расширение Chrome

Движок отделён от страницы: расширению нужен только свой приёмник файлов (`chrome.downloads.download`
с путём в `filename`). Тогда загрузка продолжится и при закрытой вкладке.
